| Код | Требования                                                                                                       | Комментарий                                                                     |
|-----|------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------|
| F   | Функциональные (Functionality)                                                                                   |                                                                                 |
| F1  | Собственник квартиры может открыть дверь своего подъезда магнитным ключем.                                       |                                                                                 |
| F2  | Собственник квартиры может открыть дверь своего подъезда с помощью функции распознавания.                        |                                                                                 |
| F3  | Собственник может открыть дверь своего подъезда по звонку из дверного домофона.                                  |                                                                                 |
| F4  | Собственник может добавить образы себя и своих домочадцев для распознавания.                                     |                                                                                 |
| F5  | Собственник может добавить номер свих автомобителей для автоматического открытия шлагбаума.                      |                                                                                 |
| F6  | Устройство на шлагбауме распознает номер автомобиля и автоматически открывает его, если номер добавлен в список. |                                                                                 |
| F7  | Собственник может открыть шлагбаум с помощью магнитного ключа.                                                   |                                                                                 |
| U   | Удобство использования (Usability)                                                                               |                                                                                 |
| U1  | Функция распознавания лиц и номеров должна работать корректно.                                                   | Частота корректного распознавания должна превышать 95%                          |
| R   | Надёжность (Reliability)                                                                                         |                                                                                 |
| R1  | Все устройства должны открываться с помощью магнитных ключей в любых случаях.                                    |                                                                                 |
| P   | Производительность (Performance)                                                                                 |                                                                                 |
| P1  | Распознавание образов должно занимать меньше 5 сек.                                                              |                                                                                 |
| S   | Поддерживаемость (Supportability)                                                                                |                                                                                 |
| S1  | Должна быть возможность мониторинга работоспособности каждого устройства.                                        | Администратор должен иметь возможность обслуживать систему без выхода "в поля". |
| +R  | + Ограничения (Restrictions)                                                                                     |                                                                                 |
| +R1 | Шлагбаумы содержат в себе аккумуляторы, требующие замены по регламенту.                                          | Замена аккумулятора по регламенту каждые 3 месяца.                              |
